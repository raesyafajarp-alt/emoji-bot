# Your Agent in One Emoji

## Entry

🧭

One glyph: the compass (U+1F9ED). It stands for an AI agent that takes a
goal and finds its own way there — it points at a destination and implies
the journey to reach it, without a map being handed to it. It reads
instantly at small size, it is specific to autonomous wayfinding, and it is
not the obvious robot or smiley.

## How to run

```sh
python3 main.py
```

This writes exactly one emoji — `🧭`, nothing else, no trailing newline —
to `/output/entry.txt`.

The program is deterministic: every run writes the same single byte
sequence.
